# MVC-Project
> *Model-View-Controller* is a software architectural design pattern that divides an application into three components: model for data and rules, view for display, and controller for coordinating between model and view. 
---

## About this Repository
This repository contains a by-pair practice activity for **Applications Development & Emerging Technologies (ADET)** to master version control using Git and GitHub. It features an **ASP.NET Core MVC** application structure, where each member gets to maintain their own feature branch dedicated for their personal portfolio page.

## How to Clone & Run

2. Open the `.sln` or `.slnx` file inside `WebApplication1` in Visual Studio Code or Visual Studio Community
3. Press the green Run button or hit F5
